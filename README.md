Primeira atividade em HTML
# 🏎️ JDM: Nissan Silvia S14 Kouki Aero

Uma página web informativa e estática desenvolvida com **HTML5 semântico**, abordando as especificações técnicas, história e características do icônico carro esportivo japonês **Nissan Silvia S14 Kouki Aero**.

---

## 🎯 Objetivo do Projeto

Este projeto foi desenvolvido como um exercício prático de desenvolvimento web para consolidar o uso e a boa estruturação de **tags semânticas do HTML5**, organização de conteúdo através de tabelas e listas, e acessibilidade estrutural.

---

## 🛠️ Tecnologias Utilizadas

* **HTML5:** Estruturação semântica da página (`<article>`, `<header>`, `<section>`, `<time>`, `<table>`, `<footer>`).

---

## 📌 Conteúdo Abordado na Página

- **Visão Geral:** Introdução ao modelo Kouki e seu significado na cultura de carros JDM.
- **Especificações Técnicas:** Listagem das características mecânicas (motor SR20DET, tração RWD, etc.).
- **Tabelas de Dados:** 
  - Dimensões do veículo.
  - Comparativo de desempenho entre motores turbo (SR20DET) e aspirado (SR20DE).
